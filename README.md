# Widget for Bank App
Учебный проект, цель которого создать функционал для банковского приложения, суть которого заключается в том, что оно
умеет маскировать номер карты или счета по желанию клиента

## Описание функций
1. Модуль `src/masks.py` содержит:
    + `get_mask_card_number` - Функция, которая маскирует номер банковской карты
    + `get_mask_account` - Функция, которая маскирует номер счета

2. Модуль `widget.py` содержит:
    + `mask_account_card` - Функция, которая обрабатывает счет или карту
    + `get_date` - Функция, которая форматирует дату

3. Модуль `processing.py` содержит:
   + `filter_by_state` - Функция, которая сортирует список словарей по ключу
   + `sort_by_date` - Функция, которая сортирует список по дате

## Установка и использование
Для использования этого небольшого зародыша на функциональную программу Вам понадобиться python и командная строка,
через которую и запускается этот шедевр
- `python masks.py`
- `python processing.py`
- `python widget.py`
